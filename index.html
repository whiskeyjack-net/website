Whiskeyjack

A design system for thumb-first apps that ship one web codebase to desktop and mobile through Tauri. Every component proved itself in a shipping app before it was extracted.

Install

  • Starter kit

    A new app with everything below wired in. Add --tauri for a desktop shell, --tray for a tray icon.

    npm create whiskeyjack@latest

  • Design system

    Tokens, themes, the Tailwind preset and the React components.

    npm i @whiskeyjack-net/design-system

  • Component registry

    Copies one component’s source into your repo, shadcn-style.

    npx shadcn add https://whiskeyjack.net/r/button.json

  • i18n

    The react-i18next setup every app here shares.

    npm i @whiskeyjack-net/i18n

  • Tauri pack

    Window controls, the OS accent color and update UX for desktop builds.

    npm i @whiskeyjack-net/tauri

  • Tauri crate

    The Rust commands the Tauri pack calls, for your src-tauri.

    cargo add whiskeyjack-tauri
